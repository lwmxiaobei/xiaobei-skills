# 踩过的坑

## Codex 生图

- **stdin 必须接 /dev/null**：`codex exec` 在后台跑时 stdin 不关，会一直等 "Reading additional input from stdin"。gen_img.sh 已经接好。
- **没出图时不能用 `ls -t "$DIR"/*.png(N)`**：glob 为空时 ls 列的是当前目录，会把别的文件（比如日志）当成图复制过去，得到一张打不开的"图"。gen_img.sh 已改成数组 glob，没图就报 FAIL。
- **网络失败**：`image generation failed: connection failed` 时有发生，重跑那一张。批量生图时写一个任务表（输出、提示词、参考图），失败的单独重跑。
- **结果要看**：偶尔排成两列而不是两行、少画一个姿势、把物品画成别的、角色颜色走样。切图前先看原图。
- **品红底**：所有画风都用 #FF00FF。绿幕会把西兰花、树叶抠掉。提示词里写清角色不含品红和紫色。
- 用全局安装的旧版 codex 会失败（写死的模型已下线），gen_img.sh 用 npx 调 `@openai/codex@0.160.1`。

## 切图、对齐

- 两个姿势挨得近会被并成一块：`cut.py --gap 6`。默认 gap 28 是为了把汗滴、动作线并回角色，近的时候反而会误并。
- 剪纸风有纸片投影、黏土风有软阴影，切出来边上会带一圈浅色：`--tol 60` 比默认 28 干净；prep_assets.py 的 clean 再按底色反解边缘透明度。
- 系统 python3 没有 scipy：用项目 `.venv/bin/python` 跑 cut.py 和 prep_assets.py。
- 对齐参考帧选站着的帧，`--frac` 两脚站立 0.25–0.35、鱼 1.0。参考帧选错了，换帧时角色会跳。

## Fish Audio 配音

- 模型 `s2.1-pro-free`，公共音色按 reference_id 调用。key 走 manim-explainer-video 的查找顺序，不要打印。
- **感叹词会读歪**："Mmm! Yes, I do!" 连续两次被读成 "Hmm"。用真单词（Yummy!）代替拟声词。
- 每次合成结果不同。某条不好，删掉 `audio/takes/` 里对应的文件再跑 tts.py；文件名是音色、语速、文字、第几条的哈希，按修改时间找最新的那条也行。
- 领念 3 遍是 3 条不同的 take（语气自然变化），齐声是每个角色各一条。
- 合成完用 mlx-whisper 转写（`uvx --from mlx-whisper …`）核对几条，尤其是短句和感叹句。

## 渲染

- **速度**：扁平风每帧约 4 ms 绘制 + 50 ms PNG 编码，整集 4 段并行约 70 秒。其他画风每帧 150–220 ms，一拍二的（蜡笔、剪纸、黏土）自动跳过重复帧，整集 4 段并行约 8–10 分钟（10 核 Mac）。渲染放后台跑。
- 慢在 SVG 位移滤镜（蜡笔、剪纸、水彩的抖动）。噪声已经预先算成图（feImage），每帧不再重算 feTurbulence；还嫌慢就减少 K.layer 的层数。
- 抖动滤镜的噪声图异步加载，clip.js 会等 `K.ready`。自己改 clip.js 时别把这个等待去掉，否则前几帧没有抖动。
- 并行渲染的分段点取偶数帧（render_all.py 已处理），每段开头是关键帧，ffmpeg concat 直接拼不重编码。
- 加了新图要重跑 build.py：spec 只登记 build.py 运行时 `代码工程/assets/` 里已有的图。
- render.py 自带的本地服务器原来是单线程、排队位只有 5 个：素材多（扁平风 55 张图）又有几个渲染进程并行时，浏览器同时发的请求被拒，报图片加载失败或语法文件请求失败。已改成多线程、排队位 256。别再换回 `socketserver.TCPServer`。

## 画面

- 代码画的东西没放进 K.layer，或者在 layer 里用了外面的 c 画：扁平风看不出问题，其他画风这部分没有材质，和周围不搭。
- 颜色写死（`'#9ED67A'`）而不是 `K.P.grass`：换画风后颜色不跟着变。
- 剪纸、黏土每个填充都带投影，密集的小块（格子、圆点）会脏：`g.plain = true`。
- 单词卡没有物品图时只放字（自动居中）；跟读环节左边的大图卡要自己画，没图的单词别进 quiz。
- 吃东西的咬一口要和音效同一个时刻（`l.t1 - 0.05` 和 `"at": "end", "offset": -0.05`），否则咔嚓声盖住单词开头的辅音。
